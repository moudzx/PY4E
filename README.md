## Contents
 
- **Lab 1** – variables, types, numeric literals, basic I/O (17 exercises)
- **Lab 2** – conditionals, pay/grade calculators, sets (10 exercises)
- **Lab 3** – functions, GCD/LCM, boolean logic (9 exercises)
- **Lab 4** – digit sums, uniqueness checks, palindrome loops (7 exercises)
- **Lab 5** – string parsing, word-guess game, ASCII animation (3 exercises)
- **Lab 6** – pangram check, coordinate walker, file merging (3 exercises)
- **Lab 7** – mailbox log parsing (senders, domains, weekday counts) (4 exercises)
- **TD8** – dict diffing, nested dict/trie construction, list comprehensions (5 exercises)
- **Dictionaries & Sets** – file encrypt/decrypt, unique words, date formatting (4 exercises)


## Notes
 
Each function is self-contained and can be imported/called directly if you don't want the GUI. </br>
See `EXERCISES` at the bottom of the file for the full list of exercise functions.
